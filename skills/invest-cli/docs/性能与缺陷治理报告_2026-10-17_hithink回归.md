# hithink 主源静默失效 — 回归定位与处置（2026-10-17）

## 0. 一句话

`a1c4923`（10-15 的冷启动优化）删掉 hithink 的模块级 `urllib` 导入后，只在
`_request` 里补了 `urllib.parse`；`_default_http_get` 仍引用 `urllib.request/error`，
首次真实取数即 `NameError`。同花顺是 A 股/基金链首，于是整条主路静默降级：
`stock` 冷取 5.9s（应为 0.6s）、`fund` 3.8s（应为 0.8s），且 A 股快照丢掉 5 年年报序列。

## 1. 现象（可复现）

```bash
cd ~/.agents/skills/invest-cli
INVEST_CLI_CACHE_DIR=$(mktemp -d) ./.venv/bin/python scripts/invest_cli.py stock 600519 --json
# 修复前：source=eastmoney，data 只有 10 个扁平字段，无 financials_history
# 修复后：source=hithink，quote/valuation/financials/financials_history 齐全
```

逐源计时（同一进程、空缓存）：

```
hithink   ok=False   0.5ms   hithink 请求异常: name 'urllib' is not defined
mxds      ok=False  2703ms   未找到匹配标的（表格信封，契约要求 dict）
eastmoney ok=True   2877ms
```

`fund` 全链失败时，错误信封会把 `name 'urllib' is not defined` 原样打给用户——
内部实现细节泄漏到 CLI 错误通道。

## 2. 根因

`a1c4923` 的 diff：

```diff
-import urllib.error
-import urllib.parse
-import urllib.request
...
 def _request(...):
+    import urllib.parse
```

同一提交里 `tencent.py` 改对了（`_http_get` 内补 `import urllib.request`，并把
`urllib.error` 从 except 里去掉）；hithink 只补了 `parse`，`_default_http_get`
的两个名字没人补。**半途而废的懒导入重构**，不是设计问题。

## 3. 为什么 550 条测试全绿

`test_hithink.py` 的所有用例都注入 `http_get` 桩，`_default_http_get` 一次都没被执行。
mock 掉的边界就是回归的藏身处。

## 4. 处置

| 文件 | 改动 |
|---|---|
| `scripts/sources/hithink.py` | `_default_http_get` 内补 `import urllib.error/request`（保住懒导入本意，不在模块顶层） |
| `data-sources.yaml` | mxds 的 `coverage` 摘掉 `stock, fund`——`c722407` 之后快照类工具必然拒绝表格，留着只是每次白等 2~2.7s；`intent mxds` 直调 `auto()` 不受影响 |
| `scripts/sources/ttskill.py` | 补 `Optional`（`F821`，注解被 `__future__` 掩盖，`get_type_hints` 会炸） |
| `scripts/test_adapter_wiring.py` | **新增**：对 hithink/tencent 的默认 getter 做「构造 Request → guarded_open 桩 → 解析」的真实路径测试；锁 mxds 不在 stock/fund 链；全适配器可导入 |
| `test_hithink.py` / `test_route.py` / `test_research_cmd.py` | 裸跑入口改用 `pytest.main`：手工调用会在带 fixture 的用例上抛 `TypeError`（旧清单还引用过已改名的函数） |
| `test_skill_integrity.py` | 补 `import pytest`（无 WorkBuddy 路由页的机器上会 `NameError`） |

## 6. 能力口径（必须说清）

同花顺没有总市值端点（`prices/snapshot` 与 `valuations/snapshot` 均已核对原始响应），
所以恢复 hithink 后终端「总市值」显示 `-`。这**不是本次引入的**：10-15 之前 hithink
正常工作时同样没有该字段，两天的东财快照才是异常态。需要总市值时走
`invest-cli quote <代码>`（0.2s，腾讯源含 `mktcap`）。若要补回，可用同源恒等式
`PB_MRQ × 归母净资产` 派生（约 1% 偏差）并标 `derived`，留作后续，不在本次混入。
